# 简单刮削器 0.2.1

- 媒体库条目的“更多”及右键菜单提供媒体库设置和移除操作。
- 设置弹窗提供“应用”和“取消”，移除媒体库使用独立确认弹窗。
- 窗口先显示，再在后台读取媒体库与缓存；加载状态清晰可见。
- 用户级 Windows 安装包提供开始菜单和已安装应用入口。
- 所有发行形式共用固定用户数据目录，升级保留设置、缓存和重命名历史。

推荐下载 `SimpleScraper-0.2.1-win-x64-setup.exe`。已有版本可以直接安装升级。

便携使用可下载 `SimpleScraper-0.2.1-win-x64.zip` 并完整解压，或下载单文件 `SimpleScraper-0.2.1-win-x64.exe`。

需要 Windows 10 1809 及以上 x64 系统。TMDB 搜索需要在设置中填写自己的 API 密钥。
