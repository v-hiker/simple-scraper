# 简单刮削器 0.2.0

- Windows 安装包：开始菜单入口、已安装应用注册和用户级安装。
- 固定安装目录与个人数据目录，升级保留设置、媒体库、缓存和重命名历史。
- 由 GitHub Actions 测试、构建并生成全部发布文件。

推荐下载 `SimpleScraper-0.2.0-win-x64-setup.exe`。已有版本可以直接安装升级。

便携使用可下载 `SimpleScraper-0.2.0-win-x64.zip` 并完整解压，或下载单文件 `SimpleScraper-0.2.0-win-x64.exe`。

需要 Windows 10 1809 及以上 x64 系统。TMDB 搜索需要在设置中填写自己的 API 密钥。
