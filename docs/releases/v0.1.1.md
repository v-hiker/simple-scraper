# 简单刮削器 0.1.1

新增可直接运行的 Windows x64 单文件版，并缩小自包含运行包。无须预装 .NET 或 Windows App SDK；首次启动会自动解包运行库，设置与媒体库记录仍保存在 `%LOCALAPPDATA%/SimpleScraper`。

下载体积：单文件 EXE 约 **95.6 MB**，ZIP 约 **96.7 MB**；相比 0.1.0 的约 111.8 MB ZIP，分别减少约 **14.5%** 和 **13.5%**。

## 下载

- **EXE 单文件版**：下载 `SimpleScraper-0.1.1-win-x64.exe`，直接运行。
- **ZIP 便携版**：下载 `SimpleScraper-0.1.1-win-x64.zip`，完整解压后运行 `SimpleScraper.exe`。
- 各文件旁的 `.sha256` 用于核对下载完整性。

## 更新

- 关闭额外的 ReadyToRun 编译并压缩单文件载荷，减少下载体积；保留完整运行库与反射式数据契约。
- 修复单文件与目录发布切换时的 WinRT 清单缓存，并补全启动所需的四个编译 XAML 资源。
- 使用固定的 PRI 资源文件名，支持带版本号或重命名后的单文件 EXE。
- 单文件内包含 Fluent 图标、使用指南、MIT 许可证和第三方原始许可文件；构建验证这些内容的字节与来源一致。
- README 和发布页加入两张真实应用截图。截图使用虚构演示媒体，未包含个人库或 API 密钥。

本地业务与列表投影回归共 1290 + 40422 项断言通过。最终版本名的单文件实际完成冷启动、中文资源显示、季集展开、编辑取消和主题重启恢复；浏览器“(1)”名称的副本另验证了冷启动与资源显示。真实 TMDB 联网与完整刮削流程的范围见[验证记录](https://github.com/v-hiker/simple-scraper/blob/main/docs/VALIDATION.md)。
