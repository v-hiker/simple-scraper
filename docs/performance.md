# 列表加载与扫描性能

点击刷新时，应用依次扫描媒体目录、保存本机扫描缓存、复制缓存并应用已保存的匹配与编辑、在后台生成列表行、绑定列表和详情，再保存界面状态。重新选择已有缓存的库时，可跳过目录扫描。

列表投影不读取媒体文件。剧集解析使用每次投影独立的索引，将远端剧集按季集编号和 ID 查找；重复编号仍按原规则视为歧义。作品、季、剧集的显示文档与计数只计算一次，多列共享结果。缓存只在一次投影中有效，因此修改编号、匹配或编辑后重新刷新会获得最新值。季详情解析也复用一次索引。

列表数据在后台计算，XAML 控件的绑定仍在 UI 线程执行。后一次投影会取消前一次，过期结果通过版本检查丢弃；加载取消会同时取消该次列表投影。列表控件保留视口虚拟化。

## 本机阶段日志

手动刷新后，可查看 `%LOCALAPPDATA%\SimpleScraper\logs\library-performance.jsonl`。如果通过 `SIMPLE_SCRAPER_DATA_HOME` 指定独立数据目录，则日志位于该目录的 `logs` 子目录。每一行记录随机生成的操作 ID、阶段、毫秒耗时、作品数、可用时的行数和是否主动刷新；总耗时还记录完成、取消、失败或被后续操作替代的状态。日志不记录媒体路径、媒体名称、API 密钥或元数据内容。

| 阶段 | 测量范围 |
| --- | --- |
| `cache-load` | 从内存或本机 JSON 读取已有缓存；主动刷新时跳过 |
| `scan` | 媒体目录扫描，可能涉及 SMB 网络文件系统 |
| `cache-save` | 写入本机扫描缓存 |
| `copy-apply` | 复制缓存并应用保存的匹配、编号与编辑 |
| `rows-project` | 后台生成行值和树形结构 |
| `rows-bind` | 同步更新列、ItemsSource、选中项与计数 |
| `selection-details` | 更新选中项详情；所选页可能读取 NFO 或请求制作人员 |
| `state-save` | 保存本机库设置和界面状态 |
| `load-total` | 本次加载操作的总墙钟时间 |

`rows-bind` 不包含后续 XAML 布局、绘制或图片完成下载的时间。被取消或失败的操作可能没有全部阶段。比较同一个操作 ID 的记录，可判断慢在网络目录扫描、后台计算还是绑定与详情，不应将内存投影基准当作 SMB 扫描或完整窗口首帧时间。

## 回归与基准

默认 `scripts/test.ps1` 会检查新旧投影的树形结构与列值一致性，覆盖中文、英文、过滤、排序、多季、编辑、手动绑定、评分回填、歧义剧集、额外视频、排除项和取消。性能基准使用合成的内存媒体数据，不访问网络盘或真实媒体，也不运行 UI 自动化。

完整基准可通过以下命令复跑，默认只使用合成数据：

```powershell
./scripts/performance.ps1
```

2026-10-03 本机 .NET 10 Release x64 合成基准在每种规模预热后测量三次，取中位数。默认九列、作品和季均展开，比较的是后台行值与树形结构生成，不包含 XAML 控件创建、布局、网络扫描或图片下载。

| 单季剧集数 | 原投影 | 索引与缓存投影 |
| --- | ---: | ---: |
| 500 | 32.19 ms | 2.47 ms |
| 2000 | 179.77 ms | 3.65 ms |
| 5000 | 1194.34 ms | 7.15 ms |

5000 集时，单次测量线程的分配量由约 92.19 MB 降至 14.17 MB。默认季详情投影由约 37.28 ms 降至 0.78 ms。小视图建立索引也有固定成本；一次已有保存树的只读比较中，163 行从 0.77 ms 变为 1.66 ms。因此这些结果只证明消除了大库的重复扫描，不代表每种小视图都更快，也不代表网络盘刷新已经完成实际窗口验收。

## SMB 扫描实测

迁移前后的主扫描流程基本沿用，本次定位的 SMB 热点是原有的重复目录枚举与素材候选存在检查；这些对比不能单独证明迁移造成了性能回归。

扫描通过只读文件系统接口取得目录清单，每个目录在一次扫描中只枚举一次。海报、季封面与 NFO 路径从清单查找，不再逐个候选调用 `File.Exists`；作品之间默认最多四路并发，返回结果仍按目录排序。每个作品的 NFO 只读取一次，XML 缓存随该作品扫描结束释放。

2026-10-03 对同一个真实 SMB 库作只读比较，均得到 106 部作品、2815 个视频。原扫描流程一次耗时 44.26 秒；优化后两次分别为 11.50 和 9.70 秒。序列化后的完整扫描结果 SHA-256 一致，媒体文件和保存的匹配状态未写入。本机缓存加载与复制的中位耗时分别约 98 和 160 毫秒。

这些数值只测量扫描器，网络负载与缓存状态会影响结果，不承诺固定倍率。测试范围和交互验证边界见 [验证记录](VALIDATION.md)。新构建的完整窗口交互仍需手动刷新，并结合阶段日志检查。
