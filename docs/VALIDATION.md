记录日期：2026-10-03。以下区分源码检查、模拟服务测试和实际窗口操作；构建或进程启动本身不作为完整交互验收。

## 自动化业务回归

本地 .NET 10 业务测试执行器已完成 **1290 项断言**，独立列表投影回归已完成 **40422 项断言**。媒体目录与个人配置使用隔离的临时夹具，HTTP 使用模拟响应，没有使用用户的真实媒体或个人 API 密钥。

覆盖范围包括媒体识别与季集映射、额外视频、NFO 和图片输出、重命名预览及冲突、状态持久化、元数据编辑、简介翻译、适配器取消/重试/错误处理，以及独立实现的 JSON 数据契约和文件名工具。新默认列、已有显式隐藏设置的恢复、中文“集数”列名和仅 TMDB 的默认来源均已通过回归。

扫描回归还检查每个目录在一次扫描里只读取一次、所需 NFO 只打开一次、刷新重建库存、只读接口、取消、四作品并发上限、稳定结果顺序和单调进度，以及 NFO 编号回退、特别篇、额外视频和图片优先级。列表回归将来源索引、预解析元数据和新投影与原行为比较，包含评分回填、重复编号歧义、手动绑定与编辑。

## 实际窗口操作

Windows 应用窗口曾实际启动，并完成一次真实 Bangumi 搜索，返回了搜索结果。该结果只证明已执行的窗口与搜索流程；不能推导其他来源、全部设置或完整刮削流程已经通过验收。

窗口测试使用隔离的电影 NFO 和零字节占位 MKV。操作前后的逐文件字节哈希一致，测试夹具未被修改；没有使用或修改个人真实媒体。

用户随后中止了 UI 自动化。主题切换、设置保存与重启恢复等交互尚未完成完整验收，后续检查应由用户手动执行或在再次授权自动操作后进行。当前记录不声称全部 UI 已验证。

## TMDB 联网范围

默认搜索来源为 TMDB，默认密钥为空。模拟 HTTP 测试验证了请求、数据映射、取消、重试以及缺少密钥时的提示。此次没有使用个人密钥完成真实 TMDB 搜索/详情/图片下载的完整联网验收，因此不能将模拟测试结果表述为 Live TMDB 已验收。

## 只读 SMB 扫描与内存投影

同一真实 SMB 媒体库的只读非 UI 扫描，旧流程一次基线为 **44.26 秒**，优化流程两次为 **9.70–11.50 秒**。三次均返回 **106 个作品、2815 个视频**，完整扫描结果的语义哈希一致。测试不刮削、不重命名、不修改媒体或用户状态；没有通过 UI 操作该库。网络响应和操作系统缓存会影响耗时，这些观测不承诺固定速度或倍率。

合成目录读取延迟的隔离夹具检查了四作品并发和相同返回结果；Release 合成内存投影基准另覆盖 500、2000、5000 集规模。内存投影、SMB 扫描与实际窗口首帧是不同阶段；具体方法、数值与日志边界见 [性能记录](performance.md)。本轮没有恢复被中止的 UI 自动化，新构建的手动网络盘刷新体验仍待验收。

## 工程与来源检查

项目依赖方向为 App → Infrastructure → Core；Core 与 Infrastructure 无 WinUI 类型依赖。发布源码采用 UTF-8 无 BOM，个人配置和私有核验产物不进入源码分发。

对迁移输入的已提交文件进行了整文件比对和连续代码 token 检查，另核对了旧命名空间、原图标/文档及疑似凭据。审计报告留在本地核验目录，不作为公开源码的一部分。来源说明见 [PROVENANCE](PROVENANCE.md)，图标生成过程见 [图标记录](icon-design.md)。技术相似度检查用于定位需要复核的内容，不作权利归属或许可认证。
