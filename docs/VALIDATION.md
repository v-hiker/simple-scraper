## 只读 SMB 扫描与内存投影

同一真实 SMB 媒体库的只读非 UI 扫描，旧流程一次基线为 **44.26 秒**，优化流程两次为 **9.70–11.50 秒**。三次均返回 **106 个作品、2815 个视频**，完整扫描结果的语义哈希一致。测试不刮削、不重命名、不修改媒体或用户状态；没有通过 UI 操作该库。网络响应和操作系统缓存会影响耗时，这些观测不承诺固定速度或倍率。

合成目录读取延迟的隔离夹具检查了四作品并发和相同返回结果；Release 合成内存投影基准另覆盖 500、2000、5000 集规模。内存投影、SMB 扫描与实际窗口首帧是不同阶段；具体方法、数值与日志边界见 [性能记录](performance.md)。本轮没有恢复被中止的 UI 自动化，新构建的手动网络盘刷新体验仍待验收。

## 工程与来源检查

项目依赖方向为 App → Infrastructure → Core；Core 与 Infrastructure 无 WinUI 类型依赖。发布源码采用 UTF-8 无 BOM，个人配置和私有核验产物不进入源码分发。

对迁移输入的已提交文件进行了整文件比对和连续代码 token 检查，另核对了旧命名空间、原图标/文档及疑似凭据。审计报告留在本地核验目录，不作为公开源码的一部分。来源说明见 [PROVENANCE](PROVENANCE.md)，图标生成过程见 [图标记录](icon-design.md)。技术相似度检查用于定位需要复核的内容，不作权利归属或许可认证。
