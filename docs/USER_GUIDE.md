# 简单刮削器使用指南

## 建立媒体库

打开应用，点击“添加媒体库”，选择电影或电视剧的根目录。首次刷新按目录结构和文件名识别作品。文件不会在扫描时移动。可筛选未匹配、缺少 NFO、缺少海报或需要检查的条目。

剧集可展开作品、季和集。不能确定的命名与混合集数需要人工确认。使用右侧详情查看本地 NFO 或已匹配的数据。

## 匹配与刮削

首次使用默认只选择 TMDB。TMDB 需填写个人 API 密钥；“获取密钥”打开官方页面。可在设置中选择 Bangumi 或多个默认来源；Bangumi 适合动画条目的公开检索。

选中作品并使用“搜索并匹配”。检查标题、年份和来源后确认。分季作品可以分别选择来源；比较集数时确认特殊篇、重复编号和缺失集。确认后执行刮削，生成对应媒体服务器使用的 NFO 和图片。

有数据的文件默认保留。需要更新或覆盖时使用相应的元数据更新/图片操作，并查看结果与警告。

## 编辑

双击作品或使用“编辑元数据”。可以编辑作品、季与集的信息、演职员及简介。保存前检查评分、日期和必填标题。取消关闭不提交修改；左下角状态反映正在执行的任务。

简介翻译在设置中选择服务。网络翻译需要联网；LibreTranslate 或其他服务的地址、密钥由你自行配置。翻译结果保存在独立缓存中。

## 重命名

使用“重命名与整理”查看作品目录和文件的目标路径。先处理冲突、排除额外视频和错误集数，再确认执行。相匹配的字幕等伴随文件随视频处理。重命名历史用于检查或回退；回退也可能遇到外部修改和目标文件冲突。

## 偏好与数据

界面支持中文、英文与系统语言，浅色、深色与系统主题。界面语言变更重启后生效。媒体元数据语言与界面语言独立。

Ctrl+F 聚焦筛选；F5 刷新；左右方向键展开或折叠剧集。默认列表包含季数、集数和评分，以及标题、年份、类型、匹配状态、NFO、海报。集数列直接显示作品/季的计数或单集的编号，不添加“视频数”等文字；无法确定的编号仍保留原始线索。列设置可调整显示、顺序和宽度，已保存的隐藏偏好不会被新默认值覆盖；重置布局恢复默认列。

配置、缓存和历史：`%LOCALAPPDATA%/SimpleScraper`。卸载/替换程序文件不会自动删除这些数据。旧改造版数据不会自动导入；需要迁移时先备份并按发布指南处理。
