# 列表性能与输出回归

这个独立控制台项目将应用的纯 C# 行投影源文件链接到测试中，不加载 WinUI，不访问媒体文件或网络。

在项目根目录运行：

```powershell
./scripts/performance.ps1
```

测试将改造前的列表算法与生产投影比较，覆盖全部 15 列、中文和英文、各排序方向和过滤状态。合成资料包含多季、跨季绑定、缺失评分回填、元数据编辑、重复集歧义、缺失来源、额外视频、排除文件、待确认编号、本地资料和图像状态。500、2000、5000 剧集的展开树使用 9 个默认列测量耗时及当前线程分配量。

可以通过 `-SnapshotFile` 和 `-StateFile` 指定现有缓存和匹配状态，测试加载缓存、复制资料、叠加记录和折叠树投影的成本。此模式只读取这两个文件，前后比较文件 SHA-256；输出只有资料数量、文件大小、耗时和分配量，没有作品名称、媒体路径或凭据。

合成资料计时对每种规模和算法进行三次同规模预热，记录三次同步样本并报告中位数；缓存阶段记录三次样本。它用于比较本机算法成本，不作为跨机器的硬性性能门槛，也不测量 XAML 布局、缩略图解码或网络共享目录枚举。
